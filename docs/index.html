WHY WILD

少一点工具，
多一点创造。

每一个功能都围绕同一个目标：让你从打开程序到看到开发板运行，中间少几步。

01

单窗口工作流

编辑器、串口监视器、编译输出在同一屏。拖动分隔线，把空间留给正在做的事。

02

ESP32 开箱即用

一键下载 Arduino CLI，一键安装 ESP32 开发支持。安装完成后，完整板卡列表自动出现。

03

为中国网络设计

默认使用 Espressif 中国镜像。CLI 走 Arduino 官方 CDN，ESP32 core 和工具链从 dl.espressif.cn 下载。

04

上传更可靠

上传前释放串口，失败自动重试；针对原生 USB 开发板补充重连流程和中文提示。

05

顺手的串口监视器

波特率切换、自动滚动、UTF-8 增量解码，中文不会被切成乱码；回车发送，自动追加 CRLF。

06

纯本地，无账号

没有 AI、没有遥测、没有插件市场。代码、配置和串口数据都留在你的电脑上。

01

下载并运行

解压后双击 wild-ide.exe。免安装；配置和草稿保存在 %APPDATA%\WildIDE。

02

安装 ESP32 支持

按顶部提示下载 Arduino CLI，再安装 ESP32 开发支持。中国大陆网络默认使用镜像。

03

编译，然后上传

选择开发板和串口。F7 编译，F8 编译并上传。打开串口查看开发板输出。

快捷键 F7编译 F8上传 Ctrl S保存 Ctrl Shift S另存为 Ctrl O打开 Enter发送

还没有安装 ESP32 支持时，开发板下拉框只显示提示；安装完成后会自动读取完整板卡列表。

PHILOSOPHY

工具应该
退到工作流后面。

“一个顺手的工具，应该让你忘记它的存在。”

Wild IDE 从一个很具体的挫败感开始：只想让一块 ESP32 闪个灯，却要先穿过项目树、插件、配置和一堆不认识的概念。

所以我们把界面压到最少：一个编辑器、一个串口、一个输出面板。没有 AI 补全，没有账号，没有插件市场。不是反对这些功能，而是这个工具不需要它们。

它首先为中文用户和中国大陆网络设计。默认镜像、明确的中文提示、能复现的上传流程，比多十个功能更重要。

少即是多

每个界面元素都要证明自己值得占据空间。

本地优先

代码、配置、串口数据都不离开你的电脑。

默认正确

为中国网络、原生 USB 板和真实失败路径做默认处理。

BEFORE YOU GO

几个常见问题。

为什么目前只有 Windows？

第一个测试包只构建了 Windows x64。Wild IDE 使用 Rust + egui，本身可以跨平台；是否提供 macOS / Linux 版本，取决于早期反馈。

为什么只支持 ESP32？

当前版本专注 ESP32 Arduino 体系。内部保留了通用 FQBN 处理，但还没有为其他平台准备板卡列表。

上传失败怎么办？

先关闭其他串口工具和 Wild IDE 的串口，拔插开发板；原生 USB 板可以按一下 RST。仍失败时按住 BOOT 再点上传，看到 Connecting... 后松开。

以后会加入 AI 吗？

不会。Wild IDE 的目标是简单、本地、可预测。没有账号、没有遥测，也没有插件市场。
